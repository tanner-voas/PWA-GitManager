- JOB-02/TEL-03: preserve working archive transfer, cancellation, validation and native sharing. Stage diagnostics remain asynchronous. Authorization failures are not retried; diagnostic failure never prevents archive delivery. Maximum additional wait eight seconds. Share activity after the download if testing preparation history.

Collector reads links on eligible ticks, prioritizes the active run then jobs updated in the past 15 minutes, then other correlated runs, failures and older observations. Generic queued details can acquire job correlation without overwriting historical archive records. Active controller scans may take an alternate discovery slot without consuming the normal cursor; active work uses existing two-minute catch-up cadence, even with a small backlog. Existing rate-limit/backpressure gates, queue caps and per-tick provider lookup budget remain. No new Actions executions. This does not guarantee detailed records before a very short automatic capture closes; late discovery can still occur in later capture periods. Additional internal history reads are bounded by existing job-history retention/lookup limits.
- TEL-11/TEL-16: a separate Usage view in Settings displays observed account-wide UTC today/month-to-date aggregates for Drive calls, backup observations, Translate estimated attempted characters/requests, Speech estimated attempted characters/requests and cache hits. Displays recorded-day count, last verified usage backup and next scheduled backup; optional previously observed provider-reported Drive storage usage/limit with timestamp. Missing values are not treated as zero. The detailed archive is not added to aggregate totals. No additional provider API calls, price assumptions or quota enforcement. Other provider billing, authoritative denominators, free-tier and rate-limit reconciliation, and fuller source health remain open.

Preserve scheduled usage backup processing even if detailed archive flushing fails; re-arm outstanding due times. Expose bounded failure reason and due date, clear failure after verified retry. No backup frequency, retention or account ownership changes.
